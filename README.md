# Ангелина Маевская — сайт художника

Сайт-витрина картин Ангелины Маевской (Могилёв, Беларусь): акрил на холсте, картины в наличии и на заказ под интерьер.

Весь сайт — один файл `index.html`: тексты, фото и видео встроены в него. Открывается в любом браузере без сборки.

## Что есть на сайте

- каталог картин в наличии и лента архивных работ (повтор под заказ);
- просмотр картины в масштабе рядом с диваном и человеком;
- примерка картины на фото своей стены: перемещение, размер, перспектива, освещение и тень;
- разделы «Под ваш интерьер», «Обо мне», доставка, упаковка и уход, отзывы, контакты.

## Как изменить тексты и картины

Данные сайта лежат в `index.html` внутри блока `<script type="application/json" id="site-data">`.
Встроенный редактор (кнопка «Редактировать сайт») публикует изменения только в версии сайта на claude.ai. На GitHub Pages правки нужно вносить в этот блок и загружать файл заново.
